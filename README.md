## What is this?

A Unity VR experience where the player holds a cricket bat via VR controllers and hits balls with physics-based swing mechanics. Built for standalone VR headsets.

## 🎮 Gameplay

- Pick up a cricket bat in VR
- Swing at incoming balls with realistic physics
- Score tracking and hit feedback

## 🚀 Open in Unity

1. Clone the repo
2. Unity Hub → Add Project → select folder
3. Check `ProjectSettings/ProjectVersion.txt` for Unity version
4. Connect your VR headset and build
